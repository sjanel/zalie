# Keyboard shortcuts

On macOS, ++ctrl++ is ++cmd++.

| Shortcut | Action |
| -------- | ------ |
| ++ctrl+enter++ | Fetch: send the active request (from anywhere, even while typing) |
| ++esc++ | Cancel the request in flight |
| ++ctrl+t++ | New unsaved request |
| ++ctrl+w++ | Close the tab |
| ++ctrl+tab++ / ++ctrl+shift+tab++ | Next / previous tab |
| ++ctrl+l++ | Edit the URL |
| ++ctrl+f++ | Find in the response body |
| ++ctrl+k++ | Filter the requests of the sidebar |
| ++ctrl+s++ | Save everything now |
| ++ctrl+b++ | Show / hide the sidebar |
| ++ctrl+j++ | Show / hide the inspector |
| ++ctrl+equal++ / ++ctrl+minus++ / ++ctrl+0++ | Zoom in / out / reset |

In the response body: ++ctrl+c++ copies the selected lines, ++ctrl+a++ selects all, ++enter++ / ++shift+enter++ go
to the next / previous match of the find field.
